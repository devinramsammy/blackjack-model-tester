# Blackjack Model Tester

♤ ♡ ♧ ♢

Test blackjack decision making models using ML inference in the browser.

## Technologies Used

- Next.js 16
- React 19
- TypeScript
- ONNX Runtime Web
- Zustand
- Tailwind CSS
- shadcn/ui
- Vitest
- uPlot
- Motion

## Game Rules

- **Dealer stands on soft 17** - The dealer must stand on any hand value of 17 or higher, including soft 17 (Ace + 6)

## Model Repository

**[blackjack-trainer](https://github.com/devinramsammy/blackjack-trainer)** - Training code and model files
